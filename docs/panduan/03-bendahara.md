# Bendahara
Tiga pembukuan terpisah: **Pembayaran santri** (tagihan, pembayaran, kuitansi, tunggakan), **Tabungan santri** (setoran/penarikan, saldo), **Kas operasional** (pemasukan/pengeluaran). Koreksi dilakukan lewat transaksi koreksi bertanda alasan, bukan menimpa. Nomor transaksi/kuitansi otomatis dan unik. Laporan: Pusat Laporan › Bendahara (PDF/Excel/cetak).
