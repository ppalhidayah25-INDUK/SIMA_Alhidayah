# Manajemen Pengguna dan Aktivitas Sistem (Super Admin)
Tambah/ubah akun (hanya 3 role), aktif/nonaktif, ubah/reset password, **Keamanan akun** (sesi aktif, riwayat login, password sementara tampil sekali, buka kunci). Akun Super Admin terakhir yang aktif tidak dapat dinonaktifkan. Aktivitas Sistem: log tak dapat diubah, bisa difilter dan diekspor.
