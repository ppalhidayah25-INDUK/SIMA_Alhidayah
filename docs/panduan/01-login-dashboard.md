# Login dan Dashboard
- Buka `/sima`, masukkan username/email dan password. Tiga role: Super Admin, Bendahara, Keamanan.
- Akun terkunci sementara setelah beberapa kali gagal login (batas diatur di Pengaturan › Sesi & Keamanan). Hubungi Super Admin.
- Bila memakai password sementara, sistem meminta Anda membuat password baru sebelum lanjut (min. 12 karakter, huruf besar, kecil, angka).
- Tombol kunci di header: ubah password sendiri. Logout mengakhiri sesi.
- Dashboard menampilkan ringkasan sesuai role: Super Admin (santri, alumni, pengurus, pengajar, asrama, keuangan, keamanan, pendidikan, konten, backup, aktivitas terbaru); Bendahara dan Keamanan melihat dashboard modul masing-masing.
