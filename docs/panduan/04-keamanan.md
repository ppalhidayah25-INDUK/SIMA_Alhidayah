# Keamanan
Pelanggaran (kategori, tingkat), pembinaan, dan perizinan santri (izin, kembali, terlambat). Nomor dokumen otomatis unik. Dashboard menampilkan pelanggaran, pembinaan, izin berlangsung, dan santri belum kembali. Laporan di Pusat Laporan › Keamanan. Role Bendahara tidak dapat membuka modul ini.
