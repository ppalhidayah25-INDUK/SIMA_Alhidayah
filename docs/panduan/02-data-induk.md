# Santri, Alumni, Pengurus, Pengajar, Asrama (Super Admin)
- **Santri**: tambah/ubah data, pindah asrama/kamar, jadikan alumni (dengan status dan tahun keluar), koreksi status alumni (wajib alasan), lihat riwayat. NIS unik. Data kosong tampil "Belum diisi".
- **Alumni**: daftar santri berstatus alumni; alumni tidak dihitung sebagai penghuni asrama aktif.
- **Pengurus / Pengajar**: data, jabatan/divisi, periode, penugasan, riwayat. ID pengajar unik.
- **Asrama & Kamar**: kapasitas kamar dan penghuni aktif; pemindahan tercatat di riwayat.
- Penghapusan diganti arsip; data tidak dihapus permanen.

## Langkah singkat (sesuai menu aplikasi)
- **Tambah santri**: Data Santri › Santri Putra/Putri › tombol tambah; isi nama, NIS, data wali. **Cari**: kotak pencarian nama/NIS dan filter asrama/kamar.
- **Pindah kamar**: buka santri › Penempatan; pilih kamar sejenis dan belum penuh.
- **Jadikan alumni**: santri › Pindah ke alumni; pilih lulus/berhenti dan tahun keluar. **Koreksi** di Data Alumni (wajib alasan).
- **Pengurus**: buat Jabatan/Divisi/Periode dulu, lalu tambah pengurus. **Pengajar**: tambah, atur penugasan.
- **Asrama & Kamar**: tambah asrama (putra/putri), tambah kamar dengan kapasitas.
